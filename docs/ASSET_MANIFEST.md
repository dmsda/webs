# ASSET_MANIFEST.md — Visual Asset Registry & Attribution

## 1. Overview
This registry catalogs all graphic, branding, and photographic assets utilized within the Pallet Ross landing page. All visual assets are stored locally within the repository to guarantee reproducible offline execution, zero layout shifts, and zero reliance on external third-party hosts.
